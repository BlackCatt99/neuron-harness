# 档位判断模板（注入主模型；机械信号是强制升档触发器，不是档位判定器）

## 机械信号（硬触发，脚本落盘，来源三层）
1. 用户消息首行显式标记 `[新任务]/[切换]` → SIGNAL-switch；`[改依赖]/[依赖变更]` → SIGNAL-dep（脚本自动识别，不过主模型）
2. 子代理回写首行 TASK-SWITCH → SIGNAL-switch（Approve 时脚本落盘）
3. 主模型语义判断后用 `-Mode Signal -Signal switch|dep -TaskId <id>` 补落（独立命令，LogRaw 之后仍可补；补充来源，不是唯一来源）
另有：约束覆盖（Supersede 自动落）、里程碑（Assemble 机械警告）。

## 升降档规则（钉死，不许摇摆）
- 有机械信号 → **至少档 2**，语义判断不能降档
- 无机械信号 → 语义可升档（判据：换子任务/改接口/改既有方案），但必须用 -Mode Signal 补落留痕（LogRaw 已执行过，Signal 是独立补落入口）
- 里程碑信号 → 至少档 3，只能升不能降

## 语义升档依据（无信号时的判断）
- 新消息目标与工作集「当前施工面/未决问题」直接连续 → 档 1
- 换子任务/换模块/改接口/改既有方案 → 档 2 + 用 -Mode Signal 补落
- 用户明说「收尾/新阶段/重估/整理」→ 档 3

输出：`档位: 1|2|3 ；理由: <一句话> ；信号: <机械信号或无>`
